# BiblioTech - Gestion des commandes

## Présentation

BiblioTech est un site web qui permet de gérer les clients, les livres et les commandes d'une boutique de livres.

## Fonctionnalités

- Afficher le nombre de clients, de livres et de commandes.
- Rechercher une commande par nom du client.
- Filtrer les commandes par statut et catégorie.
- Consulter les détails d'une commande.
- Afficher le montant total des commandes.

## Technologies utilisées

- HTML
- CSS
- Bootstrap
- JavaScript
- JSON
- Git et GitHub

## Lancement

Ouvrir le projet avec un serveur local pour charger les fichiers JSON, puis accéder au site depuis le navigateur.
